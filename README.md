
# Data Lake Anomaly Detection Pipeline

### Projeto de Portfólio | Engenharia de Software | Dados e Inteligência Artificial

## Sobre o Projeto

O **Data Lake Anomaly Detection Pipeline** é um projeto acadêmico que propõe o desenvolvimento de uma solução automatizada para identificação de anomalias em dados financeiros, com foco na análise da **Margem de Contribuição**.

Em ambientes corporativos com grandes volumes de informações, a validação dos resultados financeiros ainda depende de processos manuais, planilhas eletrônicas e análises realizadas por diferentes equipes. Esse cenário pode dificultar a identificação de inconsistências, gerar retrabalho e comprometer a agilidade das análises durante o fechamento financeiro.

A proposta do projeto é utilizar uma arquitetura baseada em **Data Lake**, integrada a técnicas de **Machine Learning**, para centralizar, processar e analisar dados financeiros de maneira estruturada, escalável e automatizada.

## Objetivo

Desenvolver um pipeline de dados em ambiente de nuvem capaz de apoiar a identificação de comportamentos atípicos em informações financeiras, contribuindo para a confiabilidade dos indicadores e a eficiência dos processos de validação.

A solução busca:

- Centralizar e estruturar dados financeiros provenientes de sistemas corporativos.
- Automatizar o processamento e a validação dos dados.
- Aplicar técnicas de Machine Learning para identificar possíveis anomalias.
- Apoiar a investigação de inconsistências por meio de dashboards e alertas automatizados.
- Reduzir a dependência de análises manuais e o retrabalho operacional.

## Visão Geral da Solução

O projeto contempla um fluxo de processamento composto pelas seguintes etapas:

**Ingestão de Dados → Validação e Tratamento → Processamento Analítico → Detecção de Anomalias → Visualização e Alertas**

A arquitetura proposta utiliza tecnologias como **Python, Google Cloud Platform (GCP) e Machine Learning**, buscando oferecer uma solução escalável e compatível com ambientes corporativos.

O sistema tem caráter complementar às ferramentas financeiras existentes, sem substituir os processos oficiais de fechamento, consolidação ou gestão contábil.
